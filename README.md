## Twine

Twine is an open-source tool for telling interactive, nonlinear stories.

This snap is a community-maintained unofficial build of [Twine](https://github.com/klembot/twinejs).

[![Get it from the Snap Store](https://snapcraft.io/static/images/badges/en/snap-store-black.svg)](https://snapcraft.io/twinejs)

## Install

Install on any [supported Linux](https://snapcraft.io/docs/installing-snapd) distribution:

```
snap install twinejs
```
